================================================================================
                           EXPORT SPECIFICATIONS
================================================================================

3D MODELS:
  Format: GLTF 2.0 Binary (.glb)
  - Embedded textures
  - Draco compression for large meshes
  - Y-up coordinate system
  - Meters as unit scale

TEXTURES:
  Format: PNG (with alpha) or JPG (no alpha)
  - Power-of-two dimensions (512, 1024, 2048, 4096)
  - PNG for UI elements, normal maps
  - JPG for diffuse where alpha not needed

AUDIO:
  Format: OGG Vorbis
  - 44.1kHz sample rate
  - Mono for SFX, Stereo for music/ambience
  - -14 to -6 dB loudness range

VIDEO:
  Format: WebM (VP9 codec)
  - 720×480 for VHS content (period-accurate)
  - 1920×1080 for overlays
  - Variable bitrate, quality 80%

ANIMATIONS:
  Format: GLTF 2.0 (.glb) with embedded animations
  - Or separate .glb per animation for modularity
  - 30 FPS standard
  - Bake all constraints before export
